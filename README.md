# Personalized-Exploratory-Course-Recommendation-System

📌 Project Overview

The Personalized Exploratory Course Recommendation System is a machine learning-based project designed to help students select suitable exploratory elective courses based on their academic profiles, interests, skills, and preferences.

The system uses Data Science techniques and Random Forest algorithms to analyze student data, predict course suitability, and generate personalized course recommendations.

It also includes an academic performance prediction component using SGPA.

🎯 Objectives

- Analyze student academic profiles and course preferences.
- Perform data cleaning and exploratory data analysis (EDA).
- Identify patterns in student interests and course selections.
- Recommend suitable exploratory courses using Machine Learning.
- Predict course suitability as High, Medium, or Low.
- Evaluate recommendation accuracy and academic performance prediction.

📊 Dataset

The project uses student profiles, course interaction records, and an exploratory course catalogue.

The dataset includes information about:

- Student academic performance (CGPA and SGPA)
- Interests and skills
- Preferred course difficulty and workload
- Course selections and interactions
- Course eligibility and characteristics

⚙️ Methodology

1. Data Collection: Collect student profiles, course information, and interaction records.
2. Data Cleaning: Handle missing values, duplicates, inconsistent categories, and invalid entries.
3. Exploratory Data Analysis: Visualize patterns, correlations, and course preferences.
4. Feature Engineering: Generate student-course compatibility features.
5. Model Training: Train Random Forest models for suitability classification and SGPA estimation.
6. Course Recommendation: Rank eligible courses based on predicted suitability.
7. Model Evaluation: Evaluate classification, recommendation, and regression performance.
